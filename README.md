## Conventions

- **Error:** predicted − observed retained strength, in percentage points. A positive error is non-conservative.
- **Programme-level dispersion (M1–M3):** each programme's held-out predictions come from a different outer-fold model, so the dispersion of programme bias for M1–M3 includes variation among the fitted models.
